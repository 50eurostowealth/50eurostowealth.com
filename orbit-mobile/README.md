# ORBIT Mobile

Multi-agent decision and execution assistant.

## MVP
- Mission intake
- Specialist panel
- Independent recommendations
- Critic/adversarial review
- Director synthesis
- Action plan
- Experiment/result log

## Stack
Expo + React Native + TypeScript. Expo supports one codebase for Android, iOS and web, and EAS Build can produce installable Android/iOS binaries. See https://docs.expo.dev/.

## Agent roles
Director, Research, Product, Growth, Sales, Finance, Engineering, Legal/Risk, Operations, Skeptic.

## Important
No agent can claim an action was executed unless an external tool confirms it. Financial actions require explicit human approval.
